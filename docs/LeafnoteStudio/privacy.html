Privacy Policy

Leafnote Pin Manager · Last updated 20 October 2026

In short: Leafnote Pin Manager is a private tool used by one person to publish pins to their own Pinterest account. It has no other users, collects no data from anyone, and shares nothing with anybody.

What this application is

Leafnote Pin Manager is a personal command-line script used by the owner of the Etsy shop LeafnoteStudio to publish plant care card images to their own Pinterest boards. It is not distributed, not offered as a service, and has no users other than its owner.

What data it accesses

Through the Pinterest API, acting solely as the authenticated account owner, it:

  • reads the list of boards on the owner's own Pinterest account, in order to know where to publish;
  • reads the owner's own account username, to confirm the connection is working;
  • creates pins on the owner's own boards.

It does not read, request, or store any data belonging to other Pinterest users. It does not access other Pinners' pins, boards, profiles, followers or activity.

What data it stores

An OAuth access token and refresh token are written to a local file on the owner's own computer so the script does not have to re-authorise on every run. That file is excluded from version control and is never transmitted anywhere except back to Pinterest for authentication.

A local record of which pins have already been published is kept so that re-running the script does not create duplicates. It contains only pin IDs and titles the owner wrote.

No database, no server, and no analytics are involved.

What is shared

Nothing. No data is sold, shared, transmitted to third parties, or used for advertising, profiling or training. There are no third-party trackers or analytics in this application.

Images published

The images published as pins are plant care cards created by the shop owner and hosted on this same site. They contain no personal data.

Retention and deletion

Tokens are kept only while the tool is in use and can be revoked at any time by the owner from Pinterest's own account settings, which immediately ends this application's access. Deleting the local file removes the stored credentials entirely.

Children

This application is not directed at children and has no users other than its owner.

Changes

If what the tool does changes, this page is updated. The date at the top reflects the current version.

Contact

Questions about this policy can be sent through the LeafnoteStudio Etsy shop's contact form.
